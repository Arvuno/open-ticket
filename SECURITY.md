# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via our Discord support server or create a private security advisory on GitHub.

Please do not create public issues for security vulnerabilities.

## Security Updates

Security updates are released as needed. Please keep your installation up to date.

Thank you for helping keep Open Ticket secure!
